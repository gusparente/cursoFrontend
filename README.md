# Ruido Maker - Tienda de Instrumentos Musicales

## Propósito de la página

**Ruido Maker** es un sitio web temático diseñado para la venta de instrumentos musicales. El proyecto demuestra una estructura semántica HTML5 correcta, contenido multimedia integrado y estilos CSS profesionales con **Flexbox**, **Grid** y **Media Queries**.

## Estructura del sitio

### Etiquetas semánticas utilizadas
- **`<header>`**: Encabezado con nombre de la marca y eslogan
- **`<nav>`**: Barra de navegación con **lista desordenada (`<ul>`)** de enlaces
- **`<main>`**: Contenedor del contenido principal
- **`<section>`**: Cinco secciones principales (Inicio, Productos, Reseñas, Multimedia, Contacto)
- **`<footer>`**: Pie de página con enlaces de navegación

## Lista de navegación implementada

La navegación principal utiliza una **lista desordenada (`<ul>`)** con enlaces internos:

```html
<ul>
    <li><a href="#inicio">Inicio</a></li>
    <li><a href="#productos">Productos</a></li>
    <li><a href="#reseñas">Reseñas</a></li>
    <li><a href="#multimedia">Multimedia</a></li>
    <li><a href="#contacto">Contacto</a></li>
</ul>
